## Shapes

### 1. Workflow `paths:` filters hand-mirror build inputs; the derived guard covers one workflow of two (2 instances, 1 live)

**Disposed as #92** (filed 2026-08-02, after independent verification against
`origin/main`).

**Pattern.** A workflow's trigger-path list restates a Docker build's input
set by hand; when it drifts, the verifying build silently does not run —
#87's own commit message names the failure mode: "An absent check looks
identical to a passing one."

**Instances.**
- `.github/workflows/nix-base.yml` omitted `lib/claude-code-token-env.sh`
  (issue #86) — fixed on `origin/main` by `1a2d031` (#87), which also added
  the *derived* guard `tests/test-nix-base-trigger-paths.sh` plus the shared
  parser `tests/lib/dockerfile.sh`. Fixed with guard; stale only in the PR-#90
  branch until merge.
- `.github/workflows/docker-build.yml:5-21` — **live on origin/main**: its
  paths (`Dockerfile, defaults/**, lib/**, projects/**, setup-claude.py,
  audit-hook`) omit `.dockerignore`, the exact input class #87 identified and
  added to nix-base.yml ("filters the repo-root context… can break a COPY
  without any COPY source changing"). A PR touching only `.dockerignore`
  never triggers the classic build. `tests/test-dockerignore-lib-allowlist.sh`
  (runs unconditionally via `test.yml`) covers only the `lib/` allowlist
  slice — a deny pattern hitting `setup-claude.py` or `audit-hook` (both
  root-Dockerfile COPY sources) merges green and breaks the next unrelated
  build.

**Absent mechanism.** No derivation of docker-build.yml's paths from the root
`Dockerfile`'s COPY set. The repo built exactly this mechanism for the sibling
workflow; `test-nix-base-trigger-paths.sh`'s scope note excludes the root
workflow only on COPY-mirroring grounds and does not record the
`.dockerignore` class for the classic build.

**Guard kind** (drift-guard test at introduction): extend the derived-paths
check to `docker-build.yml` using the already-shared `tests/lib/dockerfile.sh`
— or add `.dockerignore` to its lists and record the residual as `(—)` in the
invariants map. The preferred "second place we hand-rolled X" form, not a
novel abstraction.
